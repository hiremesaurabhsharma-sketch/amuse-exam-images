# MP GK — question images

Put MP GK question images in this folder, named in order:

- `q1.png`, `q2.png`, `q3.png`, ...

Direct link format (use this URL in the question data):

`https://raw.githubusercontent.com/hiremesaurabhsharma-sketch/amuse-exam-images/main/mp-gk/q1.png`

Replace `q1.png` with the actual file name. Keep the file names short and in order so the question numbers match.
