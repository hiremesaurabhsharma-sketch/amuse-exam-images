# geography — question images

Recovered figure/diagram images for Amuse Academy mock tests.
File names carry the test code and question number, e.g. `si07-q21-stem.png` = SI Pre Mock 7, question 21, stem image.
`-stem-composite.svg` files stack several expression fragments (in reading order) into one image.

Direct link format:

`https://raw.githubusercontent.com/hiremesaurabhsharma-sketch/amuse-exam-images/main/geography/<file-name>`
