# amuse-exam-images

Question images for Amuse Academy mock tests (MP SI, Constable, Patwari, Forest Guard).

Images in this repo are served directly via `raw.githubusercontent.com` URLs, so the test app can show them without any extra hosting.

## Folders

- `maths/` — Maths question images
- `reasoning/` — Reasoning question images
- `mp-gk/` — MP GK question images

## Naming

Name image files in order inside each folder:

- `q1.png`, `q2.png`, `q3.png`, ...

## Direct link format

Use this URL pattern in the question data (replace the folder and file name):

```
https://raw.githubusercontent.com/hiremesaurabhsharma-sketch/amuse-exam-images/main/maths/q1.png
```

Examples:

- Maths: `https://raw.githubusercontent.com/hiremesaurabhsharma-sketch/amuse-exam-images/main/maths/q1.png`
- Reasoning: `https://raw.githubusercontent.com/hiremesaurabhsharma-sketch/amuse-exam-images/main/reasoning/q1.png`
- MP GK: `https://raw.githubusercontent.com/hiremesaurabhsharma-sketch/amuse-exam-images/main/mp-gk/q1.png`
